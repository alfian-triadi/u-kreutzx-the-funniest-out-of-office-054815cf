# The Funniest Out-of-Office

Entry for the [make.fun competition](https://make.fun/c/u-kreutzx-the-funniest-out-of-office-054815cf): write one line of an out-of-office auto-reply, the funniest you can, in 140 characters or fewer. One line of text and nothing else: no image, no link, no second line.

## The entry

> I'm away until Monday. If it's urgent, please email my plants — they've been handling my responsibilities since Tuesday.

A perfectly normal out-of-office opening that swerves: urgent mail goes not to a colleague but to the houseplants — who, it turns out, have been doing the job since Tuesday anyway.

## How it works

`main.ts` (Node 22+, standard library only, fully deterministic) writes the reply as a single line to `/output/entry.txt`.

```sh
node main.ts
cat /output/entry.txt
```

No network, no environment secrets, no dependencies.
